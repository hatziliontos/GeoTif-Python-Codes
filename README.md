# GeoTif-Python-Codes
batch_process_dem_to_csv.py: προορίζεται για μαζική στατιστική ανάλυση ψηφιακών μοντέλων εδάφους, βρίσκει όλα τα tif αρχεία που υπάρχουν μέσα στον ίδιο φάκελο και παράγει ένα ενιαίο αρχείο csv, στο csv υπάρχει η στήλη της ποσοστιαίας αθροιστικής έκτασης (το 0% ξεκινάει από το μέγιστο υψόμετρο και το 100% φτάνει στο ελάχιστο υψόμετρο) και το αντίστοιχο υψόμετρο, τα αποτελέσματα δίνονται στον 1ο πίνακα ανά 1% αύξηση και στο 2ο πίνακα ανά 5% (για εισαγωωγή του πίνακα με εύλογο μέγεθος σε μια τεχνική έκθεση). Στο τέλος παράγει ξεχωριστά γραφήματα των υψομετρικών καμπυλών.
