# GeoTif-Python-Codes
batch_process_dem_to_csv.py: προορίζεται για μαζική στατιστική ανάλυση ψηφιακών μοντέλων εδάφους, βρίσκει όλα τα tif αρχεία που υπάρχουν μέσα στον ίδιο φάκελο και παράγει ξεχωριστά αρχεία csv, σε κάθε csv υπάρχει η στήλη της ποσοστιαίας αθροιστικής έκτασης (το 0% ξεκινάει από το μέγιστο υψόμετρο και το 100% φτάνει στο ελάχιστο υψόμετρο) και το αντίστοιχο υψόμετρο, τα αποτελέσματα δίνονται ανά 1% αύξηση.
