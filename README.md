# GeoTif-Python-Codes
```
batch_process_dem_to_csv.py:

 προορίζεται για μαζική στατιστική ανάλυση ψηφιακών μοντέλων εδάφους,
 βρίσκει όλα τα tif αρχεία που υπάρχουν μέσα στον ίδιο φάκελο και παράγει
 ένα ενιαίο αρχείο csv, στο csv υπάρχει η στήλη της ποσοστιαίας αθροιστικής
 έκτασης (το 0% ξεκινάει από το μέγιστο υψόμετρο και το 100% φτάνει στο ελάχιστο
 υψόμετρο) και το αντίστοιχο υψόμετρο, τα αποτελέσματα δίνονται στον 1ο πίνακα ανά
 1% αύξηση και στο 2ο πίνακα ανά 5% (για εισαγωγή του πίνακα με εύλογο μέγεθος σε
 μια τεχνική έκθεση). Στο τέλος παράγει ξεχωριστά γραφήματα των υψομετρικών καμπυλών.

 εξάρτηση από βιβλιοθήκες: απαιτείται εγκατάσταση με την βοήθεια του pip της gdal

 εκτέλεση: python310 batch_process_dem_to_csv.py

```

```
batch_process_dem_to_slope.py:

 προορίζεται για μαζική μετατροπή αρχείων DEM.tif σε αρχεία slopes.tif,
 βρίσκει όλα τα tif αρχεία που υπάρχουν μέσα στον ίδιο φάκελο και παράγει
 ξεχωριστά αρχεία tif με το ίδιο όνομα DEM και με προσθήκη του επιθέματος
 "_slope", εξαιρούνται από την μετατροπή όσα tif έχουν ήδη επίθεμα "_slope"

 εξάρτηση από βιβλιοθήκες: απαιτείται εγκατάσταση με την βοήθεια του pip των rasterio,
 numpy, matplotlib

 εκτέλεση: python310 batch_process_dem_to_slope.py

```
